# Исправления по замечаниям от 15.11.2026

1. Кнопка редактирования студенческого проекта выровнена справа рядом с жалобой.
2. Обложка черновика и проекта на доработке показывается как изображение; защищённые скриншоты открываются в превью. Для API-файлов фронт получает изображение с Bearer и освобождает blob URL после закрытия. Прежние кнопки «Обложка»/«Скриншот» были обходным интерфейсом скачивания защищённых файлов, а не требованием бэка.
3. Достижения заново загружаются с сервера при открытии профиля. Свой профиль использует `/portfolio/me/files`, чужой — публичную выдачу. Добавление и удаление работают с отдельными привязками, а не заменяют весь список по устаревшему снимку. Поэтому чужая параллельная загрузка или резюме не удаляются при добавлении сертификата.
4. Кнопка пустого избранного имеет ширину по содержимому (в проверенном окне около 142 px вместо ширины карточки 970 px).

Причина исчезновения достижений была на фронте: `GET /auth/me` не обязан содержать сертификаты, а свой профиль выбирал текущего пользователя без отдельной загрузки списка файлов. Существующие маршруты бэка поддерживают нужное поведение; изменения API не потребовались. Код, миграции и конфигурация бэка в рамках этой задачи не редактировались. Изменялись только тестовые записи БД и файлы, загруженные через обычный API.

Проверено в браузере на live API: вход тестового студента, обложка черновика и расположение кнопки, пустая поисковая выдача избранного, загрузка достижения, уход на главную и повторное открытие профиля с сохранённым файлом. Проверены входы администратора, куратора, двух компаний, доступ к их кабинетным спискам.

Данные для входа: [local-test-accounts.md](local-test-accounts.md).
