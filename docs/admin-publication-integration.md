# Интеграция административных публикаций — 15.11.2026

После merge backend-коммита `c609191` закрыты прежние ограничения создания кейсов,
стажировок и практик администратором (пункты 9 и 11 предыдущей проверки).
Код и миграции бэка со стороны фронта не изменялись.

## Фронт

- Администратор может открыть форму кейса, хакатона, олимпиады, стажировки и практики и выбрать одобренную компанию.
- Его кейсы/черновики загружаются через `/cases/mine`; в моделях сохраняется `created_by`.
- Для своих кейсов в `draft`/`revision` доступны редактирование, контрольные точки, план мероприятия и отправка на модерацию. Отзыв своей публикации с модерации также доступен.
- В стажировках и практиках есть создание и отдельный список «Мои публикации». Черновики перечитываются с сервера, в том числе при открытии карточки по URL.
- Редактирование программы доступно администратору только для своих `draft`/`revision`. Чужие и опубликованные программы не получают лишних кнопок редактирования.
- Модерация выполняется существующими действиями одобрения; автоматической публикации в обход проверки нет.

## Проверки

90 тестов фронта прошли; production-сборка успешна. Через запущенный API от `qa.admin` проверены:

1. Выбор одобренной компании, создание кейса формата hackathon, чтение из mine, редактирование.
2. Сохранение этапов, плана мероприятия, загрузка изображения и назначение обложки.
3. Отправка на модерацию и одобрение кейса.
4. Создание, редактирование, чтение из mine, модерация и публикация internship и practice.
5. Ожидаемый отказ 403 при редактировании администратором уже опубликованного кейса/программы.

Тестовые публикации помечены «[Проверка интеграции]» и остаются на локальном стенде.
Идентификаторы результата: `tmp/local-run/admin-smoke-result.json`.

## Локальный запуск

Сайт: http://localhost:3000. API: http://localhost:3005/api/v1.

```powershell
docker compose -f docker-compose.yml -f tmp/local-run/compose.yaml up -d --build server frontend
```

Используется существующая локальная конфигурация и volumes базы/хранилища.
В этой проверке скачивание make в основном Dockerfile упёрлось в DNS Alpine.
В игнорируемой папке tmp/local-run добавлен отдельный Dockerfile, который собирает
тот же код прямой командой go build без установки make. Отслеживаемые файлы бэка
и основной docker-compose.yml не менялись.
