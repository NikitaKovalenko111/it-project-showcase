# Исправления по QA от 12–13 ноября 2026

| Пункты | Изменение |
| --- | --- |
| Н-01, Н-02 | Подвал карточки компании складывается вертикально на узкой ширине. Таблица заявок прокручивается внутри своего блока и сохраняет читаемые колонки. |
| Н-03, Н-16 | Заголовок рабочей станции и карточки участников располагаются в одну колонку. |

| Н-05, Н-06 | Основные кнопки кейса занимают отдельные строки. Жалоба компактна. Бейдж заявки сохраняет ширину и размещается под именем. |
| Н-07, Н-08 | Лайк не сжимается. Ссылки студенческого проекта на телефоне располагаются вертикально. |
| Н-09, Н-10, Н-13 | Вкладки занимают один прокручиваемый ряд с указателем продолжения. Кнопки входа допускают перенос целыми словами. |
| Н-11, Н-19 | Убраны суммирующиеся отступы возле ролей администратора. Между контактами и сертификатами добавлен зазор. |
| Н-12 | Аватары поиска используют общий компонент с инициалами. |
| Н-14 | Детальные отчёты на телефоне показывают строки как карточки с подписями и всеми значениями. |
| Н-15 | Собственная страница `/profile/me` переводит компанию в её карточку, остальные нестуденческие роли — в `/account`. |
| Н-18, Н-20, Н-21 | Упорядочены промежутки подписей и полей. Текстовые поля растут по содержимому. Мобильный Markdown-редактор стажировки показывает одну колонку. |
| Н-22 | Жалоба на комментарий — флажок рядом с ответом. Ввод комментария получил рамку. |
| Н-23 | Унифицированы переносы бейджей, отступы карточек куратора, панель проектов в шапке, награды и заголовок приглашений. Сокращены длинные подсказки поиска. |
| Н-24 | Исправлены скопированные требования и награды демопубликаций, цифры реестра компаний и подписи проектов. Баллы олимпиады отображаются отдельно от организационного плана. Новые демопрофили начинают без рейтинга за неподтверждённые работы. |

Для ранее сохранённых демоданных выполняется однократное обновление известных шаблонных значений. Изменённые пользователем тексты проверяются перед обновлением.

Проверены сборка, существующие тесты и сценарии компании, администратора и студента в Chromium на ширине 360, 390, 768 и 1440 px. Проверки включают переполнение страницы, окно публикации, рабочую станцию, отчёты, таблицы пользователей, профиль, аватары и лайк.

Для таблиц администрирования выбрана горизонтальная прокрутка, для таблиц детальных отчётов — карточки. Реализация использует существующие API.
