# Интеграция фронта с текущим бэком — 14.11.2026

Изменения ограничены фронтендом. Код, миграции, конфигурация и данные бэка не менялись.

## Подключено

- Live API по умолчанию при обычном запуске и Docker-сборке; отдельная команда `npm run dev:mock`.
- Чтение `next_cursor` верхнего уровня и `total` в постраничных ответах.
- Аватар любой роли через `PUT /users/me/avatar`, отображение `avatar_file_id`, fallback на студенческое фото.
- Атомарное сохранение общего плана через `PUT /cases/{id}/stages`: точные даты исходного снимка, новый порядок, причина переноса. Проверка устаревшего плана и ошибок блокировки сохраняется.
- Отзыв итогов через `DELETE /cases/{id}/leaderboard/placements`, публикация мест также для олимпиады.
- Отзыв кейса с модерации и возврат программы в draft через существующие серверные маршруты.
- Очередь стажировок/практик читает расширенную moderation-выдачу без подмешивания публичного каталога.
- Причина блокировки аккаунта передаётся серверу; жалобы на internship доступны.
- Новая версия итогового решения доступна в submitted без оценки; superseded-версии исключены из текущего результата. Файлы другого участника той же работы сохраняются при обновлении.
- Видео MP4/WebM до 20 МиБ, выбор файлов в основных формах согласован с поддерживаемыми форматами.
- Изменение оценки её автором до публикации мест; уровень образования из студенческого поиска.
- Сводка куратора получает доступные выполнения из `/executions`, не зависит только от публичного каталога кейсов. Недоступные оценки не выдаются за нулевые результаты.

## Обнаруженные ограничения и расхождения

1. **Локальный API не запускается.** Контейнер `it-project-showcase-server` перезапускается с ошибкой `failed to load config: ... config/config.yaml: is a directory`. По пути `backend/config/config.yaml` находится каталог. Через nginx на localhost:3000 API отвечает 502. Требуется восстановить корректный конфигурационный файл и запуск сервера; фронт это исправить не может. Конфигурацию не меняли.
2. Бэк принимает JPG, PNG, WebP, PDF, TXT, ZIP, MP4 и WebM, но не DOC/DOCX/PPT/PPTX/GIF. Основные активные формы ограничены поддерживаемыми форматами. Старый ResultSubmissionModal работает только с mock-сценарием; live-сдача идёт из рабочего пространства по execution_id.
3. Куратору доступны выполнения, этапы и обсуждения, но нет общего доступа к защищённым решениям и оценкам. Поэтому соответствующая сводка показывает отсутствие доступа, а не придуманные значения.
4. Смена роли существующего пользователя и удаление файлов уже сданного этапа не имеют подходящего текущему интерфейсу серверного контракта. Фронт сообщает ограничение; имитации успешного сохранения нет.

## Проверки

Автоматические тесты фронта проверяют в том числе пагинацию текущего контракта,
атомарное сохранение плана с исходными датами, защиту от устаревшего снимка,
отзыв мест и выбор нового/старого аватара. Сквозные сценарии с настоящим API
остаются непроверенными из-за ошибки запуска сервера, описанной выше.
