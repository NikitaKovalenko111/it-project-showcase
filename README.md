# Запуск просмотра сайта

Установите Node.js версии 22.12 или новее. Откройте терминал в папке проекта и выполните:

```sh
npm ci
npm run dev
```

Откройте адрес, который напечатает Vite. Обычно это [http://localhost:3000](http://localhost:3000). Если порт занят, Vite предложит следующий свободный. Терминал должен оставаться открытым. Остановить сайт можно сочетанием Ctrl+C.

Для скачивания именно этой ветки:

```sh
git clone --branch frontend --single-branch https://github.com/NikitaKovalenko111/it-project-showcase.git
cd it-project-showcase
npm ci
npm run dev
```

Также можно скачать ZIP ветки `frontend` через GitHub, распаковать архив и выполнить первые две команды в его папке. Для первого `npm ci` нужен интернет. После установки зависимости и иллюстрации находятся локально.

## Вход для демонстрации

На странице входа есть кнопки четырёх ролей. Можно также использовать следующие логины с любым непустым паролем.

| Логин     | Роль          | Что показать                                                                |
| --------- | ------------- | --------------------------------------------------------------------------- |
| `student` | Студент       | Витрина, заявки, команды, выполнение задания, портфолио и обрезка аватара   |
| `company` | Компания      | Кейсы компании, заявки студентов, этапы и оценки работ, публикация программ |
| `curator` | Куратор       | Закреплённые студенты, мониторинг проектов и модерация публикаций           |
| `admin`   | Администратор | Пользователи, компании, модерация, жалобы и журнал действий                 |

При первом открытии отображается страница входа. Приложение всегда запускается в мок-режиме. Состояние сохраняется в localStorage браузера, поэтому после обновления остаются созданные команды, заявки, оценки и изменения профиля.

Для повторного показа исходного состояния очистите данные сайта в настройках браузера либо откройте сайт в новом приватном окне.

## Витрина IT-проектов

Учебный интерфейс для взаимодействия студентов, компаний и кураторов. В ветке находится самостоятельное приложение на React и TypeScript. Vite запускает сайт, Redux и Redux-Saga управляют состоянием и пользовательскими действиями. Локальный слой данных моделирует ответы API и проверяет права разных ролей.

Объём основных каталогов сопоставлен с локальной интеграционной базой на момент подготовки ветки. Контактные данные дополнительных участников и компаний демонстрационные.

Для команд и выполнений сохранён расширенный набор из предыдущей демоверсии. Он позволяет показать отдельные работы и оценки участников кейса, хакатона и олимпиады. Среди публикаций есть очередь на модерацию и опубликованные карточки. Новые заявки, обращения и результаты можно создать во время показа.

Данные подготовлены в `src/api/mockData.ts`, `competitionSeed.ts`, `showcaseSeed.ts` и `opportunities.ts`. Изображения из `public/demo` доступны вместе с приложением. Документы, добавленные пользователем, хранятся в браузере. Обращения в деморежиме сохраняются локально и доступны при переключении ролей в том же браузере.

## Пример последовательности показа

1. Войти студентом, открыть витрину, проверить поиск и фильтры, добавить кейс в избранное.
2. Открыть кейс с набором и подать индивидуальную заявку либо создать команду и подать командную.
3. Переключиться на компанию, найти заявку и принять её. Студенту станет доступно выполнение.
4. Показать существующий хакатон с командами, сданными решениями и оценками.
5. Войти администратором и рассмотреть публикацию в очереди, показать список пользователей и журнал.
6. Вернуться студентом, изменить профиль, выбрать фото, обрезать его и сохранить.

## Другие команды

| Команда           | Назначение                                                         |
| ----------------- | ------------------------------------------------------------------ |
| `npm run build`   | Проверить TypeScript и собрать приложение в `dist`                 |
| `npm run preview` | Открыть собранный сайт локально, обычно на `http://localhost:4173` |
| `npm test`        | Запустить проверки логики и контрактов                             |
| `npm run format`  | Отформатировать исходники                                          |

Для просмотра production-сборки сначала выполните `npm run build`, затем `npm run preview`.

## Структура

- `src/pages` — страницы ролей.
- `src/components` — карточки, формы, диалоговые окна и обрезка аватара.
- `src/api` — клиент и локальные модели данных.
- `src/store` — Redux, редьюсеры, действия и саги.
- `src/styles` — стили и адаптивная версия.
- `public/demo` — локальные иллюстрации.
- `tests` — автоматические проверки.

Выход из аккаунта позволяет выбрать другую роль. Для работы с файлами браузеру требуется доступное место в хранилище сайта. Большое количество вложений может исчерпать лимит localStorage.
