# IT Project Showcase backend

Каноническое описание API находится в [`docs/API.md`](docs/API.md), интерактивная OpenAPI-документация доступна по `GET /api/v1/docs`.

## Общая обратная связь

Автор отправляет обращение модератору через `POST /api/v1/feedback`. Принимаются до пяти приватных вложений размером до 2 МиБ каждое. Модератор принимает или отклоняет обращение, автор видит его статус в своём списке. Контракт описан в [дополнении для интеграции](docs/API_INTEGRATION_WORKFLOWS.md#обратная-связь).
