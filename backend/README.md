# IT Project Showcase backend

Каноническое описание API находится в [`docs/API.md`](docs/API.md), интерактивная OpenAPI-документация доступна по `GET /api/v1/docs`.

## Нерешённый контракт общей обратной связи

Backend поддерживает текстовые комментарии внутри выполнения через `GET/POST /api/v1/executions/{execution_id}/comments`, но отдельного маршрута общей обратной связи с администрацией и вложений к такому сообщению пока нет.

Перед реализацией необходимо согласовать:

- кому адресуется сообщение;
- категории и статусы обработки;
- кто может просматривать и отвечать;
- допустимые вложения через существующие `file_id`;
- нужно ли создавать уведомления или email.

Этот сценарий не является перепиской по приглашениям: текстовые ответы на приглашения по ранее принятому решению не реализуются.
