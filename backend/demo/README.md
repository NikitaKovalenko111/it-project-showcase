# Демобаза Showcase

В отдельном проекте Docker Compose `showcase-demo` запускаются фронтенд, API, PostgreSQL и MinIO. PostgreSQL и MinIO используют отдельные тома. API доступен на `http://127.0.0.1:13006/api/v1`. Компании названы как в постановке. Описания, наборы данных, проекты, аккаунты и программы придуманы для демонстрации и не представляют реальные предложения компаний.

Из корня репозитория в PowerShell 7:

```powershell
docker compose -f compose.demo.yaml up -d --build
pwsh -File backend/demo/seed.ps1
```

Скрипт добавляет записи, загружает 20 сгенерированных портретов, обложки кейсов и студенческих проектов и пять демонстрационных логотипов, а также прикрепляет демонстрационные документы. Файлы хранятся в MinIO. Повторный запуск сохраняет внесённые изменения и использует уже загруженные файлы. Дедлайны вычисляются при первом заполнении. Для полной пересборки данных можно удалить тома именно проекта `showcase-demo` командой `docker compose -f compose.demo.yaml down -v`, затем повторить запуск и заполнение. Команда удалит всю работу, выполненную на демостенде.

После заполнения откройте [демосайт](http://127.0.0.1:3006). Фронтенд использует API демобазы через nginx по тому же адресу. [Swagger](http://127.0.0.1:3006/api/v1/docs) также доступен через прокси.

Изменить порт сайта можно переменной `SHOWCASE_DEMO_FRONTEND_PORT`. Для прямого доступа к API можно изменить `SHOWCASE_DEMO_PORT`. Задайте нужные переменные перед запуском Compose и заполнением базы.

## Кейсы и мероприятия

| Компания | Название | Сценарий |
| --- | --- | --- |
| Газпром | Мониторинг телеметрии компрессорной станции | Собрать панель по синтетическим показаниям датчиков и обнаруживать пропуски и выход за пороги. Статус `published`. |
| Иносети | Планирование маршрутов выездных бригад | Распределить заявки между бригадами с учётом приоритетов, времени обслуживания и транспортных ограничений. Статус `in_progress`. |
| Уфанет | Хакатон «Умный мониторинг сети» | Построить карту сетевых инцидентов по синтетическим сигналам и сгруппировать связанные срабатывания. Статус `published`. |
| Актион | Поиск по базе нормативных документов | Реализовать поиск по учебному корпусу документов с подсветкой совпадений и фильтрацией по дате. Статус `moderation`. |
| IBS | Олимпиада «Алгоритмы и данные» | Решить задачи на графы, интервалы и обработку агрегатов за два тура. Статус `published`. |
| Актион | Витрина метрик редакции | Собрать ETL для учебной статистики публикаций и построить воспроизводимый отчёт по метрикам. Статус `completed`. |
| IBS | Проверка качества справочных данных | Найти дубликаты и пропуски во входном CSV и сформировать отчёт о качестве данных. Статус `draft`. |
| Газпром | Сверка показаний приборов учёта | Сопоставить два синтетических набора показаний и подготовить реестр расхождений. Статус `revision`. |
| Уфанет | Анализ обращений абонентов | Выделить повторяющиеся причины обращений на наборе обезличенных учебных записей. Статус `published`. |

Для проверки работы по кейсу откройте «Планирование маршрутов выездных бригад». У первой контрольной точки есть отправленная версия с файлом. Представитель Иносети может проверить её и продолжить сценарий оценки. У «Витрины метрик редакции» уже есть итоговая оценка 92/100 и первое место. Для новой заявки используйте открытый кейс и студента без заявки. Для регистрации можно выбрать хакатон или олимпиаду. У олимпиады открыт первый тур, у второго есть дата открытия. Стажировка Уфанета и практика IBS опубликованы. Дополнительные программы находятся в черновике, на рассмотрении и на доработке.

Есть ветка комментариев, лайки и избранное, вложение к обращению, жалоба, открытый набор в команду, приватное резюме и студенческие публикации разных статусов. Контракты и маршруты описаны в Swagger по пути `/api/v1/docs`. Доставка настоящих писем зависит от отдельной настройки SMTP.
