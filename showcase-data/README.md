# Контент для витрины IT-проектов

Версия 0.2 · 23 ноября 2026

Начните с [оглавления](CONTENTS.md), [архива хакатонов](HACKATHONS-UFA.md) или [новых концепций](HACKATHON-CONCEPTS.md). Общий каталог для Excel — catalog.csv.

## Что входит

- 36 карточек компаний и организаций, включая IBS, Инносети, Уфанет, Актион Диджитал, Форт Диалог, Газпромнефть-Цифровые решения, ИнфоТеКС и Датареон.
- 48 отраслевых кейсов, 16 новых концепций и 4 кратких описания опубликованных заданий.
- 7 архивных мероприятий Уфы с датами.
- 60 профилей и резюме, 24 карточки портфолио, 24 программы практики и стажировок.
- Команды, заявки, этапы, отчёты и комментарии.
- 7 фотографий с авторством и источниками.
- 8 входных CSV и 3 JSON-примера.

## Как работать

Тексты для просмотра — в companies, cases, students, projects и programs. JSON для передачи разработчику — в data. Изображения — assets/photos. Источники и редакторские сведения — sources. Замечания записывайте в review/feedback.csv по ID записи.

Публичные карточки не содержат повторяющихся служебных пометок. Сведения об источниках хранятся отдельно. Связь новых концепций с реальными компаниями означает подбор по профилю бизнеса, а не подтверждённый заказ; опубликованные задания и архивные события имеют собственные источники.

Код приложения не изменён. Подключение данных выполняется отдельно; инструкция — HANDOFF.md.
