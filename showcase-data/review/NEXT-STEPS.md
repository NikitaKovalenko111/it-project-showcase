# Следующая редакторская проверка

1. Просмотреть HACKATHONS-UFA.md и подтвердить выбор архива для демонстрации.
2. Выбрать 5–8 концепций из HACKATHON-CONCEPTS.md для детальной подготовки входных файлов.
3. Проверить реалистичность нагрузки, команд и критериев.
4. Подобрать уникальные иллюстрации и логотипы для утверждённых карточек.
5. Согласовать неизвестные поля архива с разработчиком.
6. Уточнить даты двух мероприятий из sources/research-queue.json.

Источники и технические сведения не нужно дублировать в каждом описании.
