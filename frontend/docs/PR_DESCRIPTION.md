## Что изменено

Фронтенд витрины IT-проектов: исправления по прогону второго спринта, модерация публикаций и адаптивная версия для телефонов и планшетов.

- Кейсы компаний и студенческие проекты отправляются куратору на рассмотрение. Автор видит статус и комментарий; общая витрина показывает только одобренные публикации. Добавлены очереди модерации и уведомления о решениях.
- Исправлены сохранение профиля, действия с заявками и изменение данных mock-сервером вне Redux. Обработанные отклики уходят из свежих заявок; повторные действия для конечных статусов недоступны.
- Унифицированы карточки рабочей станции и избранного, добавлены поиск, переходы в профили и отдельные кнопки возврата к списку и чтения описания проекта.
- Обновлены ролевые отчеты компании и куратора, фильтры и выгрузки Excel, CSV, PDF с кириллицей. Отсутствующие данные не заменяются вымышленными показателями.
- Заменен логотип, убраны лишние подписи, исправлены материалы и прокрутка обсуждения. Добавлены мобильное меню, одноколоночные формы, адаптивные карточки и внутренний скролл таблиц.

## Проверки

- `npm --prefix frontend run build` — успешно.
- `npm --prefix frontend test` — 21 тест успешно.
- `git diff --check` — без ошибок.
- Ручной прогон в Chrome: отправка и одобрение публикаций, обработка заявки, поиск, переходы в профили, скачивание трех форматов отчетов.
- Адаптивная раскладка проверена на ширинах 320, 390, 768 и 1440 px; проверены закрытие меню, прокрутка форм и отсутствие горизонтального переполнения страницы.

## Ограничения

Сценарии проверены в mock-режиме. Для live необходим серверный контракт модерации и проверка прав на чтение неопубликованных материалов. Production-авторизация, файловое хранилище и недоступная история интервью/стажировок требуют отдельной интеграции. Полная сверка с ТЗ находится в `frontend/docs/FRONTEND_TZ_AUDIT.md`, проверка мобильной версии — в `frontend/docs/MOBILE_QA.md`.
