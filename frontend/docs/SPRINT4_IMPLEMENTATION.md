# Спринт 4: фронтенд, 2 ноября 2026

Реализована часть задач Алмаза в существующем React-приложении. Полный спринт ещё не закрыт.

## Реализовано

- Отдельный маршрут `/teams`, пункт меню студента, мои команды, поиск команды по выбранному кейсу и мини-анкета на этой странице. Поиск убран из кейса, портфолио и рабочей страницы. В создание команды добавлено описание.
- Переименование «Рабочая станция» в «Активные проекты».
- Комментарий над списком, форма ответа под выбранным комментарием, свёрнутые ветки и раскрытие порциями по 10, удаление своего комментария. При наличии ответов остаётся текстовая заглушка.
- Файлы резюме, несколько материалов этапа, скриншоты результата, файлы портфолио, обложка кейса. Удаление материалов непринятого этапа и файлов портфолио с подтверждением. GitHub из профиля в заявке, результате и публикации.
- Оранжевое оформление NDA. Настройки видимости перенесены со списка в страницу проекта; приватным проектам не показывается статус модерации.
- Критерии при создании кейса: количество, названия, положительные веса. Редактирование существующих критериев запрещено в форме и mock. Оценка использует критерии кейса, каждый 0–10. Максимум N × 10; веса нормализованы к этому максимуму. Старые кейсы используют прежние десять критериев. Назначение места в индивидуальной оценке удалено.
- Программа стажировок: кнопки Markdown для заголовков, жирного текста и ссылок, предпросмотр и безопасное отображение без HTML.
- Сортировка рейтинга в обе стороны, удаление интерфейса закрепления студентов, знак рубля, уточнение статуса принятой индивидуальной заявки, кнопка избранного в кейсе без текста, жалоба внизу студенческого проекта.
- Панель количества/сортировки каталога скрывается при прокрутке вниз. Общие отступы форм, оформление выбора файлов и адаптивные стили.
- В live-входе login/password, access_token/refresh_token и запрос профиля через `/auth/me`. Регистрация использует API-клиент, в live-запросе не передаёт роль. Саморегистрация компании в live выключена до выбора согласованного сценария.

## Незавершённые пункты

- Разделение case/execution, отдельное решение каждой команды, вкладки сданных/оценённых решений и общий лидерборд.
- Экраны consent_pending и согласия участников с версией условий, модерация ревизий кейса.
- Полный snake_case-маппинг моделей, UUID справочников, серверная пагинация и отмена кейса через cancelled.
- Административные действия удаления на каждом типе содержимого.
- Полный перенос параметров кейса в правую колонку и проверка всех страниц/форм в браузере на desktop/mobile.
- Дополнительные вложения к заявке в команду; автоматическая подстановка файлов портфолио в остальные формы.

## Интеграция

Бэкенда и Swagger в этой рабочей копии нет. Новые адреса ниже являются предполагаемым контрактом и требуют сверки с Денисом:

- `POST /files/upload`: multipart `file`, ответ `{file_id,url}`. ID сохранён в моделях; полный переход всех запросов на file_id ещё не выполнен.
- `DELETE /cases/:caseId/comments/:commentId`.
- `DELETE /milestones/:milestoneId/materials/:index`: временный контракт по индексу, ответ — обновлённый этап. Для production нужно согласовать устойчивый ID материала.

Live-запросы не переключаются на mock при ошибке. В mock файлы сохраняются как data URL, лимит каждого файла 2 МБ. Большие суммарные вложения могут превышать квоту localStorage; production должен использовать файловое хранилище.
