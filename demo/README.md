# Демоданные витрины ИТ-проектов

В этой папке находятся расширенный набор, его медиа и SQL, а также отдельный [базовый набор](basic/README.md). Для проверки кабинетов, модерации, туров, NDA и вложений используйте расширенный набор.

## Загрузить в запущенный демостенд

Нужны Docker Compose и Node.js 22 или новее. Если контейнеры ещё не запущены, выполните из корня проекта:

```bash
docker compose -f compose.demo.yaml up -d --build --wait
```

На запущенном стенде примените импорт. Для Bash:

```bash
bash demo/import.sh
```

Для Windows PowerShell:

```powershell
./demo/import.ps1
```

Готовая витрина открывается на [localhost:3006](http://127.0.0.1:3006). Для отдельного проекта задайте `COMPOSE_PROJECT_NAME`, `SHOWCASE_DEMO_FRONTEND_PORT` и `SHOWCASE_DEMO_PORT` перед запуском контейнеров и импорта. Импорт проверяет название выделенной базы и роль PostgreSQL. Для расширенного и базового наборов используйте отдельные стенды, у них пересекаются демологины.

Обычные аккаунты и их сценарии описаны в [инструкции](HANDOFF.md#импорт-в-docker). Общий демопароль — `DemoShowcase2026!`. Дополнительные аккаунты:

| Логин | Что проверить |
| --- | --- |
| `demo.coverage-pending` | Запрос роли представителя компании ожидает одобрения |
| `demo.coverage-rejected` | Запрос роли куратора отклонён |
| `demo.coverage-blocked` | Вход заблокирован |

`coverage.sql` добавляет состояния модерации, жалобы, обращения, командные приглашения, планы мероприятий, оценки туров, NDA и историю переноса сроков. Импортёр загружает файлы в MinIO через API и связывает их с записями. Для наполнения уже работающего демостенда достаточно повторить команду импорта.

- 8 входных CSV и 3 JSON-примера.

## Как работать

Тексты для просмотра — в companies, cases, students, projects и programs. JSON для передачи разработчику — в data. Изображения — assets/photos. Источники и редакторские сведения — sources. Замечания записывайте в review/feedback.csv по ID записи.

Публичные карточки не содержат повторяющихся служебных пометок. Сведения об источниках хранятся отдельно. Связь новых концепций с реальными компаниями означает подбор по профилю бизнеса, а не подтверждённый заказ; опубликованные задания и архивные события имеют собственные источники.

Код приложения не изменён. Подключение данных выполняется отдельно; инструкция — HANDOFF.md.
