# Маршрут без ступеней

БиблиоМаршрут / Frontend

![Маршрут без ступеней](../assets/covers/syn_extra_case_001.jpg)

## Проблема

Посетитель не может понять, доступен ли путь между корпусами без лестниц.

## Результат

Карта маршрута с лифтами, обходами и указанием недоступных участков.

## Вход

Условная схема трёх корпусов, 18 переходов и пять ограничений доступности.

## Приёмка

Маршрут не проходит по закрытому лифту; отсутствие пути объясняется; управление работает с клавиатуры.

## Обсудить с наставником

Минимальный сценарий, ограничения входных данных и план демонстрации.
