# Найди лабораторную ошибку

РобоТропа / Разработка игр

![Найди лабораторную ошибку](../assets/covers/syn_extra_case_012.jpg)

## Проблема

Студенты учат порядок действий, но теряются при необычной ситуации на стенде.

## Результат

Короткая игра-расследование с несколькими объяснимыми развилками.

## Вход

Пять сцен, восемь улик и три варианта завершения.

## Приёмка

Ошибочное действие сопровождается объяснением; прогресс восстанавливается; нет тупика без подсказки.

## Обсудить с наставником

Минимальный сценарий, ограничения входных данных и план демонстрации.
