# Проверяемый ответ ассистента

Музейный Слой / Искусственный интеллект

![Проверяемый ответ ассистента](../assets/covers/syn_extra_case_006.jpg)

## Проблема

Помощник уверенно отвечает на вопрос, на который нет данных.

## Результат

Поиск с фрагментами-основаниями, уточнением вопроса и отказом без подтверждения.

## Вход

25 регламентов и 50 вопросов, включая конфликтующие редакции.

## Приёмка

Ответ указывает источник; конфликт не скрывается; точность сравнивается с поиском по словам.

## Обсудить с наставником

Минимальный сценарий, ограничения входных данных и план демонстрации.
