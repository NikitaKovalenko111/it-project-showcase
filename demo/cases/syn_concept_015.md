# Доставка события ровно один раз для пользователя

Датареон / Backend

![Доставка события ровно один раз для пользователя](../assets/covers/syn_concept_015.jpg)

## Ситуация

Интеграция повторяет сообщения, и заказ появляется дважды после сбоя подтверждения.

## Что сделать

Сделать идемпотентный приём и наблюдаемый повтор обработки.

## Входные данные

500 событий заказов, повторы, перестановка порядка и сбой после сохранения. Пакет входных файлов формируется перед запуском трека.

## Что показать на защите

API приёма, журнал попыток и сценарий восстановления.

## Критерии

Повтор не создаёт вторую запись; конфликт версии виден; после восстановления очередь сходится.

## Границы решения

Фокус на основном сценарии и воспроизводимой демонстрации. Внешние платёжные и производственные системы не подключаются.

## Дальнейшее развитие

Сравнить результат с базовым вариантом, собрать обратную связь пользователей и оценить стоимость сопровождения.
