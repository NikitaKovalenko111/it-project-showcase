# Диспетчер без голодания задач

Инносети / Backend

![Диспетчер без голодания задач](../assets/covers/syn_concept_003.jpg)

## Ситуация

Короткие задачи постоянно вытесняют длинные; свободные специалисты не получают подходящую работу.

## Что сделать

Сравнить FIFO и распределение с учётом квалификации, возраста заявки и загрузки.

## Входные данные

Поток событий, 12 исполнителей, матрица навыков и изменение доступности. Пакет входных файлов формируется перед запуском трека.

## Что показать на защите

API диспетчера и панель справедливости очереди.

## Критерии

Не назначать заявку дважды при параллельной обработке; показать максимальное ожидание, а не только среднее.

## Границы решения

Фокус на основном сценарии и воспроизводимой демонстрации. Внешние платёжные и производственные системы не подключаются.

## Дальнейшее развитие

Сравнить результат с базовым вариантом, собрать обратную связь пользователей и оценить стоимость сопровождения.
