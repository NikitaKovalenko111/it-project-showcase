# Ремонт по заявке

Дискретный План / Бизнес-анализ

![Ремонт по заявке](../assets/covers/syn_extra_case_008.jpg)

## Проблема

Обращения о поломках теряются между регистрацией и подтверждением ремонта.

## Результат

Маршрут заявки с ответственным, фотографией проблемы и подтверждением результата.

## Вход

Реестр помещений и 30 обращений с разными статусами.

## Приёмка

Повторное открытие не стирает прошлый ремонт; закрытие требует результата; жильцы не видят чужие контакты.

## Обсудить с наставником

Минимальный сценарий, ограничения входных данных и план демонстрации.
