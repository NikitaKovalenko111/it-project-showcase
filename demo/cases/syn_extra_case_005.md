# Пропущенная пересадка

Город На Ладони / Мобильная разработка

![Пропущенная пересадка](../assets/covers/syn_extra_case_005.jpg)

## Проблема

При задержке автобуса пассажир получает маршрут с уже недоступной пересадкой.

## Результат

Пересчёт пути с запасом времени и офлайн-карточкой остановок.

## Вход

Условные линии, расписание и поток задержек.

## Приёмка

Маршрут учитывает время перехода; устаревшее расписание обозначено; тайм-аут не стирает сохранённый путь.

## Обсудить с наставником

Минимальный сценарий, ограничения входных данных и план демонстрации.
