# Интерфейсные изображения

96 SVG-изображений подготовлены как самостоятельные графические макеты: календарь, каталог, карта, рабочая доска, диаграммы, заметки, диалог и этапы. Это изображения для карточек проектов; код приложения не менялся. Фотографии обложек — отдельные файлы, источники указаны в images.json.
