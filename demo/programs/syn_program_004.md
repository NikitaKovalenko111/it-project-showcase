# Практика: backend — Маршрутная Сетка

![Практика: backend — Маршрутная Сетка](../assets/covers/syn_program_004.jpg)

## Направление

Городская логистика.

## Задача

API маршрута с объяснением невыполнимых заказов.

## Входные знания

Go, PostgreSQL; умение объяснить свой вклад.

## Организация

6 недель, 12 часов в неделю. Один разбор с наставником в неделю. Дистанционный формат.

## Итог

Невозможное окно выделено; груз не превышает вместимость; сравнение с исходным маршрутом воспроизводимо.

## Отбор

Описание учебного проекта и знакомство с наставником. Коммерческий опыт не требуется.

## Итоговая защита

Короткая демонстрация, разбор проверок и обсуждение дальнейшего развития решения.
