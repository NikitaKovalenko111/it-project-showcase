# Материалы проекта

## Состав

Постановка задачи, входные примеры, изображения интерфейса, отчёт о проверках и презентация.

## Основной сценарий

Открыть каталог, выбрать запись, проверить пустой ввод, сохранить изменение и повторить действие.

## Приёмка

Сопоставить ожидаемое и фактическое поведение; отдельным пунктом описать ограничения.
